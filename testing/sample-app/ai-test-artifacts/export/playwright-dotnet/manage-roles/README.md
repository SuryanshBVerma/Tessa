## Signed-in sessions

Each persona uses a stored session (Playwright storage state). Tessa never writes credentials
into tests. Create each file once by signing in by hand, then keep it out of Git:

```bash
dotnet build
pwsh bin/Debug/net8.0/playwright.ps1 codegen --save-storage=.auth/admin.json http://127.0.0.1:5173
pwsh bin/Debug/net8.0/playwright.ps1 codegen --save-storage=.auth/editor.json http://127.0.0.1:5173
pwsh bin/Debug/net8.0/playwright.ps1 codegen --save-storage=.auth/viewer.json http://127.0.0.1:5173
```

- `TESSA_AUTH_ADMIN` overrides the path for **admin** (default `.auth/admin.json`)
- `TESSA_AUTH_EDITOR` overrides the path for **editor** (default `.auth/editor.json`)
- `TESSA_AUTH_VIEWER` overrides the path for **viewer** (default `.auth/viewer.json`)
