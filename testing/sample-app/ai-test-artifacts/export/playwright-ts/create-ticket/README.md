## Signed-in sessions

Each persona uses a stored session (Playwright storage state). Tessa never writes credentials
into tests. Create each file once by signing in by hand, then keep it out of Git:

```bash
npx playwright codegen --save-storage=.auth/editor.json http://127.0.0.1:5173
npx playwright codegen --save-storage=.auth/viewer.json http://127.0.0.1:5173
```

Or point the environment variables at existing files:

- `TESSA_AUTH_EDITOR` for **editor** (default `.auth/editor.json`)
- `TESSA_AUTH_VIEWER` for **viewer** (default `.auth/viewer.json`)
